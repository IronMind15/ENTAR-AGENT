## 一、背景与目的

恩特小助手（PCS 故障代码智能查询机器人）已完成 MVP 和 V2 迭代，已上线 Web 页面和钉钉 Stream 模式机器人，同事已完成实测。但目前：

1. **面向用户**：没有一份清晰的使用说明，钉钉群内新用户不知道如何有效使用
2. **面向开发者**：没有一份完整的内部设计文档，后续迭代（云部署、补充其他 sheet、经验查询等）缺少参考基准

因此需要制作两份 Word 文档，分别解决上述两个问题。

## 三、文档 1：使用说明（用户视角）

### 3.1 定位
- 面向**非技术用户**（车间、运维、售后同事）
- 语言通俗，不要术语堆砌
- 看完就会用，不需要任何技术背景

### 3.2 建议大纲

```
一、恩特小助手是什么
  - 一句话定义：PCS 设备故障代码查询助手
  - 能做什么 / 不能做什么
  - 典型使用场景（例：现场报 d4-1 了，@小助手）

二、在哪里找它
  - 钉钉群聊：任意群 @恩特小助手
  - Web 页面：浏览器打开 http://[IP]:8000（仅限局域网）

三、怎么用（核心章节）
  - 场景1：直接输入故障代码（最快，秒回）
    例：d4-1、df-8、d10-1
  - 场景2：输入故障名称或描述
    例：急停告警、外部急停信号闭合
  - 场景3：用自然语言描述问题
    例：我这个逆变器报错了怎么回事
  - 场景4：闲聊/问公司信息
    例：你是谁、恩特能源是哪家公司

四、怎么看回复
  - 回复内容解读（每个字段含义）
  - 一条结果 vs 多条结果
  - 匹配度标记（高/中）的含义

五、常见问题
  - 没查到怎么办
  - 查到的结果不对怎么办
  - 服务不可用怎么办

六、注意事项
  - 数据范围：仅限 PCS 参数表遥信（DI）sheet 的 133 条
  - 建议先用故障代码查，最快最准确
```

### 3.3 风格要求
- 口语化、带具体例子
- 每个操作步骤配截图（或文字说清楚位置）
- 篇幅：5~8 页为宜，不要太长

## 四、文档 2：设计说明（开发者视角）

### 4.1 定位
- 面向**内部开发者**、未来接手维护的人
- 技术准确，结构清晰
- 读完能理解全貌、能上手修改

### 4.2 建议大纲

```
一、项目概述
  - 背景：恩特能源 PCS 设备售后故障排查痛点
  - 目标：搭建面向中小企业的 AI Agent 全生命周期管理平台（三步走）
  - 当前进度：第一步 MVP ~ V2

二、系统架构
  - 整体架构图（用户入口 → FastAPI → 技能模块 → Chroma/LLM）
  - 核心组件清单
  - 数据流图

三、核心模块说明
  3.1 入口路由（main.py）
    - 意图路由策略（判断逻辑、优先级）
    - 聊天 vs 故障查询的分流条件
  3.2 故障查询（error_query.py）
    - 两级查询策略详解
    - 精确匹配（metadata 过滤，不调 LLM）
    - 语义搜索（Chroma + bge-small-zh-v1.5）
    - LLM 提取关键词（DeepSeek，仅用于复杂自然语言）
    - 回复格式化规则
  3.3 通用聊天（chat.py）
    - 托底功能设计
    - 系统提示词内容
  3.4 钉钉机器人（dingtalk_bot.py）
    - Stream 模式原理（为什么选它，和 Webhook 的区别）
    - 消息接收 → 路由 → 回复流程
    - reply_markdown 同步/异步注意事项

四、数据层
  - 数据源：PCS参数表 V1.6.2.xlsx
  - Chroma 向量库结构（collection 名称、metadata 字段）
  - Embedding 模型选型（BAAI/bge-small-zh-v1.5）
  - 同步脚本（sync_kb.py）工作流程

五、部署与运维
  - 本地运行步骤
  - 局域网共享（防火墙配置）
  - 钉钉机器人部署流程（开发者后台配置步骤）
  - 云服务器部署规划（待办）

六、技术选型与权衡
  - 为什么用 FastAPI（轻量、异步支持好）
  - 为什么用 Chroma（本地持久化、无额外服务依赖）
  - 为什么用 DeepSeek（性价比、国产）
  - 为什么只用 LLM 做关键词提取（省钱、省时间）

七、已知问题与改进方向
  - 当前局限（息屏断连、短关键词效果、数据覆盖窄）
  - 后续规划（云部署、补充其他 sheet、经验查询）
```

### 4.3 风格要求
- 技术准确，配合代码片段说明
- 必要的架构图/流程图（可以用文字图或截图）
- 篇幅：10~15 页
