# 📖 经验知识库 — 纠错 / 失效操作指南

> 生成时间：2026-08-04｜适用版本：v1.5.0
> 经验条目是文件粒度的（`data/experience/*.md` → Chroma `experience_kb`），
> 「纠错 = 改文件重新同步（版本替换）」「失效 = 删除条目」。本指南给管理员的具体操作步骤。

---

## 一、纠错（修改已有经验条目）

> 底层机制：`stable_document_id` 基于文件路径生成，同名文件修改后 doc_id 不变 →
> `replace_document` 两阶段换版（新版本 staging → 校验 → 激活，旧版本 retired 删除）。
> **改内容重新同步即可完成纠错，无需删旧重建。**

### 方式 A：本地文件编辑（推荐，简单直接）

```bash
# 1. 找到要纠错的条目（data/experience/ 下，文件名即条目标识）
#    例：逆变器IGBT过温告警排查.md

# 2. 用编辑器修改五段式内容（保持 ## 段落标题不变）

# 3. 重新同步（版本替换，旧版本自动下线）
python scripts/sync_experiences.py
```

### 方式 B：管理后台重新上传（同文件覆盖）

1. `/admin` → 上传 Tab → 选择「💡 经验知识」
2. 上传**同名** `.md` 文件（文件名必须一致才能触发版本替换）
3. 到「同步管理」Tab → 选 `data/experience/` → 触发同步

> ⚠️ 审核模式下：上传走审核流，`同意同步 id 经验库` 后入库，同名即替换旧版本。

---

## 二、失效（下线经验条目）

> 底层机制：Chroma 删除该 doc_id 对应的所有块。

### 方式 A：管理后台删除

1. `/admin` → 同步管理 Tab → 选 `data/experience/` 目录
2. 找到目标文件 → 删除
3. 同步管理里删除后，Chroma 中对应条目被移除

### 方式 B：直接删除文件 + 同步

```bash
# 1. 删除经验文件
rm "data/experience/逆变器IGBT过温告警排查.md"

# 2. 删除 Chroma 中对应记录（通过 /admin 同步管理删除，或如下清理）
#    同步管理 Tab 中该文件状态会被标记为已删除；确认 Chroma 中无残留块
```

## 三、注意事项

| 项 | 说明 |
|----|------|
| **段标题别改** | 五段标题 `## 故障现象 / 排查步骤 / 根因 / 解决方案 / 验证结果` 是切块和格式化的依据，纠错时只改正文，保持标题不变 |
| **每段内容别太短** | 段落 < 50 字符会被 `merge_small_chunks` 合并到相邻段（内容不丢但阶段标签覆盖），建议每段写够内容 |
| **文件名即标识** | 经验库没有编号体系，文件名是条目标识。改名 = 新条目（旧条目不会自动迁移） |
| **纠错影响检索** | 版本替换后旧版本立即下线，检索只返回新版本，无回滚；如需回滚需手动还原文件内容重新同步 |
| **审核保障** | 建议纠错/失效操作由经验条目维护人或审核人执行，避免误改他人经验 |
