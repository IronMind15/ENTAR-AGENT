## 第 3 步：审核流程真实钉钉端到端验证

### 3.1 配置固定审核人

1. 启动服务后，在钉钉单聊发：**`查看我的审核ID`**
2. 把返回的钉钉员工 ID 写入 `scripts/local_config.py`：

```python
KNOWLEDGE_REVIEW_MODE = "fixed"
KNOWLEDGE_REVIEWER_STAFF_IDS = "你的钉钉员工ID"   # 多个用逗号分隔
```

3. 重启服务。

### 3.2 端到端链路

| 步骤 | 操作 | 预期 |
|:----:|------|------|
| 1 | 普通同事在钉钉发一个 PDF | 文件保存到待处理区，不直接入库 |
| 2 | 机器人主动单聊通知固定审核人 | 收到审核申请编号 |
| 3 | 审核人发 `同意同步 申请编号` | 后台任务启动同步 |
| 4 | 同步完成 | 知识库可检索到该文件 |
| 5 | 再发一个文件，发 `拒绝同步 申请编号 原因` | 源文件保留，不进知识库 |
| 6 | 非审核人尝试审批 | 被拒绝（鉴权生效） |

> ⚠️ 注意：配置的是 `sender_staff_id / userid`（钉钉用户 ID），不是机器人回调里的 unionId。
