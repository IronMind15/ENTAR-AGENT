🏗️ 系统架构

RAG Agent 循环 + 两级快速通道 + 多端入口，实现高性价比的企业级智能问答

📡 用户入口

同事通过 Web 浏览器（http://localhost:8000）或 钉钉单聊（搜索「恩特小助手」）发送问题。 钉钉采用 Stream Mode ★ WebSocket 长连接，无需公网 IP。

🧠 Agent 循环路由

DeepSeek Function Calling 自主决策：调用故障查询工具、标准检索工具， 或直接聊天。最多 5 轮循环，支持多工具协作。注入跨会话记忆实现上下文感知。

💡 核心技术亮点

每个亮点背后都是具体的技术决策和工程落地

🧠

RAG Agent 循环

基于 DeepSeek Function Calling 的智能路由。系统自动判断用户意图——是查故障代码、搜标准文档，还是普通聊天——调用对应工具，无需人工干预。

LLM + 工具 + 记忆 + 循环
⚡

两级快速通道

故障代码 / 标准编号精确匹配走 metadata 过滤，毫秒级响应，零 LLM 调用。约 70%+ 的查询不经过大模型，API 成本降至纯 LLM 方案的 30%。

成本优化 · 极致性能
🔌

钉钉 Stream Mode

WebSocket 长连接主动连钉钉，不需要公网 IP、域名、SSL 证书。零网络配置即可上线，降低 80% 运维部署成本，适合无公网环境的中小企业。

内网友好 · 开箱即用
📄

文档全生命周期管理

上传 → 提取 → 智能切块 → 向量入库 → Web 管理 → 进度追踪。存储抽象层设计，Chroma ↔ Qdrant 一行切换。支持 PDF / Excel / Markdown 多格式。

可扩展架构 · 抽象工厂
👁️

大模型视觉 OCR

扫描 PDF 不走传统 OCR，用 MinerU VLM 大模型视觉识别直接输出 Markdown。复杂表格 / 公式 / 图表识别准确率 95%+，技术文档场景效果显著。

VLM 替代传统 OCR
🏢

企业级基础设施

SQLite 三表设计（用户 / 对话 / 权限）、钉钉用户信息自动同步、密码+细粒度权限双模式保护、统计看板、后台异步任务管理器。
