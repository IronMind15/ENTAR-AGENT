## 三、时序图（一次查询的消息交互）

**视角**：精确快速通道 / 歧义澄清 / 一般问题走 Agent 三支，加写操作二次确认。

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户（钉钉/Web）
    participant BOT as dingtalk_bot<br/>入口
    participant R as routing<br/>判定层
    participant SK as 技能层<br/>priority 100→50
    participant TOOL as tools 注册中心
    participant CH as Chroma
    participant LLM as DeepSeek

    U->>BOT: 发送消息
    BOT->>R: 消息文本
    R->>R: detect_domains 领域互斥
    alt 精确故障码 d4-1（fault 领域）
        R->>SK: 让位 error_query
        SK->>CH: 精确匹配 metadata
        CH-->>SK: 格式化结果
        SK-->>U: 秒回（不调 LLM）
    else 歧义句（多领域命中）
        R->>R: ask_clarification
        R-->>U: 反问「回 1/2 或具体项」
        U->>R: 选择 2
        R->>SK: 按选择路由
    else 一般问题（空领域）
        R->>SK: 放行 agent 循环
        SK->>LLM: Function Calling 提取意图
        LLM-->>SK: 选工具 kb_search
        SK->>TOOL: 执行工具
        TOOL->>CH: 语义检索
        CH-->>TOOL: Top-N 结果
        TOOL-->>SK: 结果 JSON
        SK-->>U: 【】标签格式化回复
    end

    Note over TOOL,LLM: 写操作（kb_create/dash_push/删除重学）<br/>先冻结参数要求确认，10min TTL<br/>确认后执行真实 handler
```

**要点**：
- 三条路径核心差异在**是否调 LLM**：精确匹配秒回（0 LLM 调用），Agent 路径一次 Function Calling
- 歧义澄清把决定权交还用户（v1.12.0 判定层治本框架核心思想）

## 四、C4 model（Context → Container）

**视角**：C4 模型四层中的前两层——系统上下文（外部依赖边界）+ 容器图（系统内部容器与数据流向）。按 Mermaid 原生 `C4Container` 语法绘制（等价于 C4 L1+L2）。

```mermaid
C4Container
  title 恩特小助手 v1.12.0 — C4 容器图（Container）

  Person(user, "用户", "钉钉单聊或 Web 页面使用者")

  Enterprise_Boundary(b0, "恩特小助手系统") {
    System_Boundary(sb1, "入口与判定") {
      Container(bot, "钉钉机器人", "Python/dingtalk-stream", "Stream 长连接接收消息")
      Container(web, "Web 服务", "FastAPI", "聊天页 /ask + 管理后台 /admin")
      Container(routing, "判定层", "Python", "detect_domains 领域互斥 + 歧义反问")
    }
    System_Boundary(sb2, "能力层") {
      Container(skills, "技能层", "Python", "故障100/PCB90/看板80/标准70/RAG50")
      Container(tools, "工具注册中心", "Python", "6 板块 10 工具，@register 唯一事实源")
      Container(capability, "能力清单", "Python", "capability_manifest.py 自动生成")
    }
    System_Boundary(sb3, "数据层") {
      ContainerDb(chroma, "Chroma 向量库", "向量数据库", "error_codes/standards/经验/自定义库")
      ContainerDb(sqlite, "SQLite", "关系数据库", "用户/会话/权限/知识库注册表/订阅")
      Container(files, "文件存储", "磁盘", "data/uploads + 钉钉文档")
    }
  }

  System_Ext(ds, "DeepSeek API", "LLM Function Calling")
  System_Ext(qwen, "qwen3.7-flash", "视觉识别")
  System_Ext(mineru, "MinerU", "扫描 PDF OCR")

  Rel(user, bot, "发消息")
  Rel(user, web, "访问页面")
  Rel(bot, routing, "文本")
  Rel(web, routing, "文本")
  Rel(routing, skills, "按领域路由")
  Rel(skills, tools, "Function Calling")
  Rel(tools, chroma, "检索/写入")
  Rel(tools, sqlite, "读写")
  Rel(tools, files, "文件管理")
  Rel(skills, ds, "LLM 调用")
  Rel(tools, qwen, "识图")
  Rel(tools, mineru, "OCR")
```

**要点**：
- C4 强调**边界**：外部依赖（DeepSeek/qwen/MinerU）与系统内部容器严格区分
- 若需更细粒度，可继续画 C4Component（每个容器内部类/模块）——当前粒度足够覆盖架构说明
