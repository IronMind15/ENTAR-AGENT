### C. 能力升级主线（10 页，每页都带「为什么/反馈/学习」）

#### 主线 1：Agent 化与记忆（2 页）
- **P5 从规则路由到 RAG Agent**（v1.1）：Function Calling 统一路由；**胡总 7/6 追问「是否标准 Agent」→ 对比四要素 → 规则路由+快速通道保留**；聊天托底合并
- **P6 记忆系统三次升级**：v1.1 会话记忆（SQLite）→ v1.2.4 JSON→SQLite → v1.5.3 双层记忆（短期+LLM 长期压缩）→ v1.6.2 KV Cache 友好（静态 system + 窗口20批量滚动，命中率 ≈0→78%）；**跨项目 5 大差距第 1 条直接落地（hello-agents ch9 / ai-agent-book ch2）**；84 组成本模拟支撑决策

#### 主线 2：知识检索（2 页）
- **P7 检索升级**（v1.3.0 + v1.4.0）：混合检索（BM25+向量 RRF）+ rerank 生效；**从 RAG 开源三件套学到**；短关键词痛点
- **P8 检索的教训**：v1.5.2 rerank 静默失效半年（KeyError 被降级保护吞掉）；**29 条评估集「先测后改」→ rerank 收益微乎其微 → 轻量库不值 → 落地配置开关**；标准跨语言检索是真缺口

#### 主线 3：文档与 OCR（2 页）
- **P9 文档管理子系统**（v1.2.1→v1.2.6）：doc_mgr 统一管道、SHA-256 版本替换、崩溃恢复；存储抽象层；P0 验收清单
- **P10 OCR 路线大切换**（v1.2.2）：PaddleOCR → MinerU 大模型视觉；**从「本地部署坑多」决策切到「大模型 API 零部署」**；MinerU 三个坑（轮询 unknown/OSS 403/200 页限制）

#### 主线 4：多部门与权限（1 页）
- **P11 多部门进化**：老板 7/20 需求 → v1.2.8 五中心 → v1.2.9 隔离修复 → v1.5.2 归属可改；权限从「没有」到「数据链路层强制」

#### 主线 5：PCB 技能（2 页）
- **P12 PCB 技能成长**（v1.4.0→v1.4.2）：9→13 类，本地秒回；钉钉即时反馈
- **P13 PCB 权威化 + 打磨**：**王哥 8/5 实测反馈** → v1.5.4 以 pcb-tools.cn 为基准 13→54 类 + v1.5.6 参数补足层；v1.5.5 40 题社区回归（7对26败→36对0败）+ \b 汉字边界 bug；公式权威 > 个人经验

#### 主线 6：并发与稳定（2 页）
- **P14 多人并发**（v1.6.0）：to_thread + 每用户锁 + 限流 20；**借鉴 hello-agents ch7 AsyncToolExecutor / ai-agent-book Flux**；一人问 LLM 全排队的痛点
- **P15 并发修复 + 韧性**：v1.6.1 锁跨循环/懒加载单例；DeepSeek 重试（10061）；**Clash 代理劫持三症状排障（10061/10054/SSL EOF）→ 国内 API 全直连 trust_env=False**

#### 主线 7：协作与通讯（1 页）
- **P16 通讯录 v1.7.0**：find_employee；**钉钉新版接口 404 → 旧版 oapi 换族**；敏感字段服务端剥离；90 员工实测

### D. 总结与展望（4 页）
- **P17 数据总览**：测试数 33→227、版本 24、PCB 54 类、缓存命中率 78-92%、员工 90、PCS 故障 133
- **P18 爬过的坑**（横切汇总）：版本兼容/Paddle 3.2.2/正则 flags/汉字 \b/代理劫持/锁跨循环/思考挤空/降级掩盖 bug/LLM 编造
- **P19 学到的最重要教训**：降级保护掩盖 bug / LLM 只用在刀刃上 / 代码就绪≠生效 / 新接口≠可用 / 权限放数据链路层 / 用数据说话（评估集+成本模拟）
- **P20 展望 v2.0**：企业知识中枢 + 多模态图片理解 + 部门知识库 + 腾讯云同步；第二步经验库进行中（~40%）

## 四、待交互确认的设计决策

进入 Stage 1 网页确认时，需要你拍板：
1. **页数**：20 页完整版？还是砍掉某条主线？（每条主线都是独立的，可增删）
2. **视觉风格**：延续暗黑霓虹风？还是换？（上次你说「之前那个并不好看」，可考虑换瑞士极简/杂志风/其他）
3. **内容取舍**：20 页是否太多？是否保留「爬过的坑」和「学到的重要教训」这两页？
4. **叙事侧重**：按能力主线讲（现在这样）还是按时间版本讲？
