## 二、一次查询的完整流程（时序）

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户（钉钉 / Web）
    participant E as 入口 main.py
    participant A as Agent 循环 agent.py
    participant Q as 快速通道
    participant T as 工具注册中心 tools/
    participant S as enhanced_search
    participant C as Chroma
    participant L as DeepSeek

    U->>E: 发送问题
    E->>A: 路由
    A->>Q: 尝试精确匹配（故障代码 d4-1 / 标准编号）
    alt 精确命中
        Q-->>U: 秒回格式化结果（不调 LLM）
    else 未命中
        A->>L: Function Calling 提取意图
        L-->>A: 选择工具
        A->>T: 执行工具
        T->>S: 混合检索（向量 + BM25）
        S->>C: 粗召回 Top-20
        C-->>S: 候选集
        S->>S: RRF 融合 + bge-reranker 重排
        S-->>T: Top-N 结果
        T-->>A: 返回 JSON
        A-->>U: 【】标签格式化回复
    end
```
