## 四、正面确认（真落地的能力）

以下能力经第二轮逐行核对，**确认为真实现**（非纸面声明），值得保留与复用：

1. **写操作治理机制**：冻结参数 + 真实 handler 结果回报，LLM 无法谎称「已执行」
2. **幻觉护栏**：零工具调用 + 完成态声明 → 强制纠偏，是 prompt 软约束之外的硬校验
3. **判定层三态**：领域互斥让位 + 歧义反问（按 user_id 隔离）+ 查询盲区兜底
4. **上下文工程**：静态 system + 历史独立轮次回放 + 动态上下文放末尾，刻意保 KV Cache 前缀稳定
5. **存储状态机**：staging/active/retired + 可见性过滤 + 两阶段换版 + 失败回滚
6. **敏感字段服务端剥离**：通讯录手机号/邮箱双保险剥离，Web 匿名用户天然拿不到
7. **安全细节**：图片 magic bytes + 8MB 守卫 + 路径白名单；MinerU ZIP 解压防护（路径穿越/符号链接/压缩比/成员数）
8. **并发治理**：DeepSeek `_LLM_SEMAPHORE=20` + 3 次指数退避（退避不占并发槽）
9. **测试纪律**：887 项 + tripwire 理念（每种回归一条变红）

## 五、优化建议（按性价比排序）

1. **堵 Web 身份伪造（C1）**：无登录前 `user` 参数降级为纯本地昵称、服务端忽略记忆归属；日志脱敏。成本低、收益最高。
2. **密钥不进镜像 + 管理端默认关闭（C2/C4）**：`.dockerignore` 加 `scripts/local_config.py`、`pack.sh` 加 `--exclude data/ knowledge_base/`；`_verify_admin_access` 改「未配密码 → 默认拒绝（仅 localhost 放行）」。
3. **修 BM25 缓存失效（C3）**：文档变更后清对应 collection 缓存键，或 `enhanced_query` 加 `force_rebuild`；补「上传学习后混合检索能命中」回归测试。
4. **写操作确认链路下沉通用层（H1）**：把钉钉入口的 pending 确认/取消/澄清解析抽成 Web 与钉钉共用函数。
5. **修看板调度漏推 + 变化误报（H4/H5/H8）**：`is_due` 加 ±5 分钟宽容窗口 + 订阅执行改异步队列（每订阅硬超时）+ `has_changes` 按 record_key 排序比较。
6. **统一 SQLite 迁移（H9）**：引入 schema_version 集中迁移，三模块收口。
7. **删活 + 校验收口（H2/H3）**：`router.delete_docs` 补 `include_hidden=True`；`validate_local_text` 覆盖 MinerU 回退本地路径。
8. **pcb_calc 拆分（L4）**：参考 tools/ 做法拆成 `calc/` 包 + 注册表，消除 3400 行单文件。

## 六、未来进化方向预测

- **近期（v1.13~v1.14，补收尾）**：真实环境端到端验收 → 修检索隐患（BM25 失效、rerank 开关、跨语言）→ 看板可靠性（漏推/变化误报/成本预算）→ 安全收尾（Web 身份、密钥进镜像、管理端默认关闭）。**「从能用到可信」的必经一步。**
- **中期（第二步经验库 + v2.0 企业中枢）**：经验库从「框架完成、内容为空」走向「低门槛提交 + LLM 自动五段式结构化 + 按热度排序」；多中心权限落地（`department`/`centers` 字段已预留，但**必须先统一 Web 身份源**）；通用文件引擎 switch-case 改注册表；VLM 图片理解接入。
- **远期（第三步 + 平台化）**：AI 辅助研发 → 会议工作流（与看板联动）→ 钉钉生态打通（群聊/审批/待办/日程）。技术形态从「单机 FastAPI + 本地 Chroma」走向「多 worker + 共享锁/活动版本指针 + 迁移框架 + 成本可观测」。

**关键判断**：它的进化天花板目前不卡在 LLM 能力，而卡在**身份信任边界**和**部署/调度形态**——把这两块补齐，第二步、第三步的能力堆叠才有稳固地基。
