# 一、恩特小助手是什么

恩特小助手是一个 PCS 设备故障代码智能查询助手。当你遇到储能变流器（PCS）报出故障代码时，不用翻手册、不用找人问——直接在钉钉群里 @恩特小助手，输入故障代码或描述，立刻就能查到故障原因和详细信息。

## 能做什么

* ✅ 输入故障代码（如 d4-1）→ 秒出故障名称、原因、地址等全部信息
* ✅ 输入故障名称或描述（如"急停告警"）→ 模糊搜索匹配结果
* ✅ 用大白话描述问题（如"逆变器报错了"）→ 理解意图后搜索
* ✅ 回答公司相关问题（恩特能源介绍、产品信息等）

## 不能做什么

* ❌ 不能控制设备、修改参数
* ❌ 不能处理非 PCS 设备的故障（如空调、照明等）
* ❌ 不能保证覆盖所有故障场景（目前只有 133 条常见故障记录）

## 典型使用场景

你在现场调试或运维时，PCS 设备面板报出故障代码 d4-1，屏幕显示「急停告警」。打开钉钉，搜索「恩特小助手」进入单聊，输入 d4-1，立刻返回：

 【名称】急停告警
 【故障原因】外部急停信号闭合
 【故障代码】d4-1
 【地址】0x3004 【位地址】bit0 【属性】R 【数据类型】bit
 【说明】1-告警，0-正常
 ……

不用翻手册、不用打电话问人，30 秒搞定。

# 二、在哪里找到它

## 方式一：钉钉单聊（推荐）

打开钉钉，在顶部搜索框搜索「恩特小助手」，点击进入聊天窗口，直接输入问题即可。

这是最推荐的使用方式——无需添加群聊、无需 @ 机器人，打开对话直接发消息，就像跟微信好友聊天一样简单。

## 方式二：Web 页面（仅限公司局域网）

在公司局域网内（连接公司 WiFi 或网线），浏览器打开以下地址：

 http://[本机IP]:8000

具体 IP 请向 IT 同事确认。打开后是一个简洁的搜索页面，输入问题即可查询。

## 方式三：钉钉群聊（即将上线）

目前群聊机器人功能正在测试中，等稳定运行后会先加入开发人员的群聊。届时可以直接在公司群里 @恩特小助手 使用。

# 三、怎么使用（核心章节）

## 场景 1：直接输入故障代码（最快 — 秒回）

这是推荐的方式。当你设备上报出故障代码时，直接把代码发过来。

示例：
 你：d4-1
 小助手：返回故障名称、原因、地址等全部信息

支持的故障代码格式：
 • 单故障码：d4-1、df-8、de-6
💡 输入故障代码是最快的方式，不需要调用大模型，毫秒级返回。

## 场景 2：输入故障名称或描述

如果你不记得故障代码，但知道故障名称或原因，直接输入即可。

示例：
 你：急停告警
 小助手：找到匹配结果，显示【名称】【故障原因】【故障代码】等

其他例子：
 • 外部急停信号闭合
 • 过流保护
 • 硬件故障
 • 通讯中断

💡 关键词越具体，匹配越精确。例如「外部急停信号闭合」比「急停」效果更好。

## 场景 3：用自然语言描述问题

如果你也不知道具体叫什么，用大白话说就行。

示例：
 你：我这个逆变器报错了怎么回事
 小助手：理解你的意思 → 提取关键词 → 搜索 → 返回匹配结果

💡 这种情况内部会调用大模型做一次关键词提取，速度会比前两种稍慢一点点，但效果更好。

## 场景 4：闲聊或问公司信息

恩特小助手也能回答一些日常问题。

示例：
 • 你是谁
 • 恩特能源是做什么的
 • 你们的 PCS 产品有哪些特点
 • 今天天气怎么样

💡 注意：日常聊天只是附带功能，小助手主要还是用来查故障的。复杂问题建议还是问专业的人。

# 四、怎么看懂回复

## 单条结果（精确匹配）

当你输入故障代码时，返回的是精确匹配结果，格式如下：

 【名称】急停告警 ← 故障名称
 【故障原因】外部急停信号闭合 ← 什么原因导致
 【故障代码】d4-1 ← 对应的故障码
 【地址】0x3004 ← 设备中的寄存器地址
 【位地址】bit0 ← 具体位
 【属性】R ← 读/写属性
 【数据类型】bit ← 数据类型
 【默认值】0
 【备注】一级 满足条件复位
 【说明】1-告警，0-正常 ← 最重要的！告警条件
 【备注2】1
 ---
 数据来源：PCS参数表 V1.6.2.xlsx → 遥信（DI） → 第51行

## 多条结果（语义搜索）

当你用关键词或自然语言搜索时，可能返回多条结果：

 🔍 找到 3 条相关信息：

 ────────── 结果 1 [高] ──────────
 【名称】急停告警
 ...

 ────────── 结果 2 [中] ──────────
 【名称】...

每条结果独立显示，匹配度标记 [高]/[中] 表示相关性：
 • [高] — 非常相关，可信度高
 • [中] — 部分相关，建议结合实际情况判断

# 五、常见问题

**Q：没查到怎么办？**

A：① 检查故障代码格式是否正确（如 d4-1 不是 d4-1-）；② 换个说法再试一次，比如把「急停」换成「外部急停信号闭合」；③ 如果确实没有，说明这条故障尚未录入系统，请联系技术同事补充数据到 Excel 中。

**Q：查到的结果不对怎么办？**

A：语义搜索是模糊匹配，匹配度标记 [中] 的结果仅供参考。建议用故障代码精确查询（如 d4-1）获得最准确的结果。

**Q：服务不可用怎么办？**

A：目前服务运行在本地电脑上，如果电脑息屏、睡眠或关机，服务会断开。请联系 IT 同事检查电脑是否在线。后续计划部署到云服务器实现 7×24 小时在线。

**Q：搜索不到「恩特小助手」怎么办？**

A：① 确认机器人服务端的电脑正在运行（联系 IT 检查）；② 确认你已经在钉钉上安装了「恩特小助手」应用——需要管理员在企业内完成授权安装后，所有员工才能搜索到。

**Q：发了消息没有回复怎么办？**

A：① 确认服务端电脑正在运行（联系 IT）；② 可能是网络问题，稍后再试；③ 如果持续无响应，联系技术团队检查服务状态。

**Q：可以查询其他设备的故障吗？**

A：目前只覆盖储能变流器（PCS）的常见故障代码，其他设备的故障暂不支持。后续会根据需求扩展。

# 六、注意事项

* 数据范围：目前仅覆盖 PCS 参数表「遥信（DI）」sheet 的 133 条故障记录，不是全部故障。
* 建议先用故障代码查：直接输入故障代码（如 d4-1）最快最准，不经过大模型处理。
* 语义搜索是辅助：当你不确定故障代码时用来缩小范围，最终以故障代码精确匹配为准。
* 服务可靠性：目前运行在本地电脑，息屏/睡眠/关机会导致服务不可用。
* 反馈渠道：如有数据遗漏或错误，请反馈给技术团队，他们会更新到 Excel 并同步。
