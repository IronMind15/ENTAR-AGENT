## ✦ 当前功能

面向公司同事的故障代码智能查询工具，已接入钉钉和 Web 两个入口。

### 🔍 精确匹配
输入 `d4-1`、`de-6` 等故障代码，毫秒级返回完整参数——名称、原因、地址、数据类型等全部信息。

✅ 已完成

### 🧠 语义搜索
记不住故障代码？输入「外部急停信号闭合」「逆变器报错」等自然描述，Chroma 向量检索找到最匹配的结果。

✅ 已完成

### 💬 通用聊天
非故障问题自动托底到 DeepSeek 对话。问天气、问公司制度、闲聊都行，像同事一样自然交流。

✅ 已完成

### 📱 钉钉机器人
搜索「恩特小助手」进入单聊即可使用。Stream 模式长连接，无需公网 IP、无需域名、无需 SSL。

✅ 已上线

### 🌐 Web 页面
http://localhost:8000 局域网内均可访问。适合办公电脑直接打开使用，与钉钉机器人共享同一后端。

✅ 已上线

### ⚡ 秒级响应
两级查询策略：精确匹配不调 LLM（毫秒级），语义搜索走本地 Chroma（秒级），LLM 只用在自然语言关键词提取。

✅ 已优化

### ⚡ 查询策略（3 级递进）

```
1️⃣ 精确匹配故障代码 → 2️⃣ 语义搜索 Chroma → 3️⃣ LLM 提取关键词 · 再搜索 → 💬 兜底 · 直接聊天
```

> 🔵 = 不调 LLM · 毫秒级 | 🟠 = 调 LLM（仅关键词提取，极小 prompt）
